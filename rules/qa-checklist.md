# Checklist QA

## Otomatis (`qa`)

- [ ] Grid: pergantian scene di kelipatan 81 frame
- [ ] Durasi: 11–22 slot
- [ ] Warna maskot = token
- [ ] Font resmi saja
- [ ] Teks/caption di dalam safe area
- [ ] VO tidak terpotong

## Manual (sebelum approve)

- [ ] Ejaan naskah
- [ ] Sinkron VO vs caption
- [ ] Warna maskot terlihat on-brand
- [ ] Brand voice (hangat, energik, singkat)
- [ ] Musik/SFX berlisensi

## Moderasi (opsional)

- Jika aktif: flag `true` di `qa-report.json` memblokir approve sampai keputusan user tercatat.
